# Course Modules
 
- **Overview of Computer Networks** - Learn computer network fundamentals, layered architecture, Internet principles, and addressing schemes (MAC, IPv4, port numbers). Write your first networked program.
    
- **Inter-Process Communication** - Explore process concepts and inter-process communication mechanisms using signals, pipes, message queues, and shared memory. Master synchronisation techniques using semaphores.
    
- **Network Programming** - Master BSD networking, host testing, and network simulation using Mininet. Learn networking APIs including IPv6-compatible interfaces. Understand TCP/IP architecture and debug programs using sock and tcpdump.
    
- **Socket Interface** - Develop Echo client-server programs using UDP, TCP, and SCTP sockets. Learn to select appropriate socket types for different applications.
    
- **Client-Server Computing Model** - Measure server performance and explore various server designs including iterative, concurrent, preforked, and threaded architectures. Develop HTTP client and server programs.
    
- **Traditional Client-Server Applications** - Build Telnet and FTP client-server programs. Develop iterative and concurrent web search engines to understand the advantages of concurrency.
    
- **Design Issues** - Explore socket operations and I/O models including blocking, non-blocking, signal-driven, and asynchronous I/O. Develop an improved str_cli() function.
    
- **Remote Procedure Calls** - Learn RPC fundamentals and the door mechanism for local RPC. Build client-server applications using Sun RPC.
    
- **Distributed Programming** - Build distributed applications using RPC to invoke remote procedures. Learn language-independent data representation and work with RPC frameworks for distributed communication.
    
- **Distributed System Design** - Explore distributed system challenges including communication, consistency, fault tolerance, and scalability. Study architectural patterns and distributed file systems (NFS and AFS).
