
# Document-Term Matrix

### DTM

A **Document-Term Matrix (DTM)** represents documents using the words they contain.

---

## Basic Idea

Each **row** represents a document.

Each **column** represents a term (word).

Each **cell** contains the **frequency** of that term in the document.

---

## Example

Suppose we have two documents:

**Document 1:**  
> "cat dog cat"

**Document 2:**  
> "dog bird"

The DTM becomes:

|  | cat | dog | bird |
|---|---:|---:|---:|
| Document 1 | 2 | 1 | 0 |
| Document 2 | 0 | 1 | 1 |

---

## How to Read It

### Document 1

`cat = 2`

→ "cat" appears **2 times**

`dog = 1`

→ "dog" appears **1 time**

`bird = 0`

→ "bird" does **not appear**

---

## Why Use DTM?

DTM converts **text into numbers**.

This allows machine learning algorithms to process text.

### Text
> "cat dog cat"

↓

### Numbers
`[2, 1, 0]`

---

## DTM in Machine Learning

DTM can be used as input for:

- **Text Classification**
- **Sentiment Analysis**
- **Document Similarity**
- **Information Retrieval**
- **Natural Language Processing**

---

# Key Idea

## Document → Words → Frequencies

A DTM tells us:

> **How many times does each term appear in each document?**

### Rows → Documents  
### Columns → Terms  
### Values → Term Frequency
