# What is Back propagation Error?

**Backpropagation** is the method used to **teach a neural network how to reduce its error**.

Simple idea:

> The network makes a prediction → checks the error → sends the error backward → updates weights to improve next prediction.

That’s why it is called **Back + Propagation**  
because the **error travels backward through the network**.

# Steps in Back propagation 

Step 1: Forward Pass
Step 2:Calculate error
Step 3:Send error backwards
Step 4:Update weights

Backpropagation is an algorithm that sends prediction error backward through a neural network to update weights and reduce future errors.
