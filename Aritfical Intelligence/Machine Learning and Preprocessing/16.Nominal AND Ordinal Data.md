

## Nominal Data

Nominal data classifies data into unordered categories where ranking doesn't matter

eg->hair color ,gender


## Ordinal Data

Ordinal data represent data with natural order ranking

eg->satisfaction level,education 



# What is the difference between LableEncoder and OneHotEncoder

OneHotEncoder convert data into multiple binary column which is ideal for nominal data where order doesn't matter

LabelEncoder converts data into the integer value such as (0,1,2,3...) and is ideal for ordinal data where category matters
